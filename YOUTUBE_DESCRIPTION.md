Title: TraceClimate — Environmental Data Review & Evidence Verification | IEEE ClimateChain Demo

Visibility: Unlisted, with a shareable link that judges can access.

Description:

TraceClimate is a working environmental evidence prototype for the Climate Data & Environmental Monitoring track of the IEEE ClimateChain Global Hackathon.

It imports CSV or public NASA POWER daily temperature data, highlights unusual readings with a rolling median/MAD model, and exports a portable SHA-256 evidence chain that can be verified against a separately retained trusted root.

Source and documentation: https://github.com/BharathGelivi/traceclimate

This 4m25s video is an edited walkthrough of genuine screenshots from the working application, with synthesized narration. The anomaly example is explicitly synthetic. The NASA example shows an actual successful public API request for Bengaluru, 1 September–15 October 2025.

The prototype verifies data integrity relative to a trusted root, not measurement accuracy. It does not deploy a blockchain or public-ledger anchor. Statistical flags require human review; no field-validated impact or fraud detection is claimed.

Built solo by Bharath Gelivi with substantial Codex AI assistance for research, design, implementation, documentation and testing. Source is MIT licensed.

NASA POWER documentation: https://power.larc.nasa.gov/docs/services/api/temporal/daily/
